Crea una navegación por pasos para {{proceso}} (por ejemplo, publicar un sitio) con cuatro pasos enlazables dentro de un nav con una lista ordenada.
Cada paso tiene un estado visible con texto además de color: completo (check), actual (aria-current="step"), requiere atención (con el motivo) y pendiente (sin enlace).
Los pasos ya alcanzados son enlaces para volver atrás; los botones Atrás y Continuar mueven el paso y actualizan un panel con aria-live. Los pasos completos usan una barra de degradado de acento.
Estilo sobrio y profesional: bordes finos de 1px, radio 8px, sombras suaves, acento azul, tokens CSS con tema claro y oscuro.
