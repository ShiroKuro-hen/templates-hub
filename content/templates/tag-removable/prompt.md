Crea un editor de etiquetas para {{contexto}}: una lista de tags, cada uno con un botón × (aria-label "Quitar etiqueta X") y un input para añadir más con Enter.
Con teclado: Enter o Espacio sobre la × elimina, Supr/Retroceso también, y el foco pasa a la etiqueta vecina.
Evita duplicados, anuncia los cambios con role="status" y muestra un mensaje cuando no queda ninguna.
Estilo sobrio y profesional: bordes finos de 1px, radio 8px, sombras suaves, acento azul, tokens CSS con tema claro y oscuro; foco visible de 2px, sin librerías.
