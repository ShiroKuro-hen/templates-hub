Crea una cuadrícula de tarjetas de {{elemento}} (por ejemplo, documentos de un espacio de trabajo) con vista previa en CSS, título y datos de edición.
Requisitos: las acciones ({{acciones}}) aparecen al pasar el cursor y también con :focus-within para quien navega con teclado, con transición breve;
en pantallas táctiles (hover: none) las acciones se muestran siempre. Botones reales con texto y foco visible, sin JavaScript y sin librerías externas.
Estilo sobrio y profesional: bordes finos de 1px, radio 8px, sombras suaves, acento azul, tokens CSS con tema claro y oscuro.
