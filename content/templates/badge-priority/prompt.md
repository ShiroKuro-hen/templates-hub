Crea badges de prioridad (Alta, Media, Baja) y etiquetas de color con punto para una lista de {{elementos}} (por ejemplo, tareas de un sprint).
La prioridad no depende solo del color: lleva un icono de 3 barras con 3, 2 o 1 barras llenas y texto visible, con "Prioridad" para lectores de pantalla.
Texto en var(--text) sobre fondo suave (--err-soft, --warn-soft, --info-soft) para cumplir contraste AA; las etiquetas {{etiquetas}} usan un punto de 8px con su color.
Estilo sobrio y profesional: bordes finos de 1px, radio 8px, sombras suaves, acento azul, tokens CSS con tema claro y oscuro.
