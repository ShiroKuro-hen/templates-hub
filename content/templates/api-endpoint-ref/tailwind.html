Crear un pedido

POST /v1/pedidos

Registra un pedido para un cliente existente. Requiere una clave de API en la cabecera Authorization.

Parámetros del cuerpo

NombreTipoUsoDescripción
cliente_idstringObligatorioIdentificador del cliente. Empieza por cli_.
totalintegerObligatorioImporte en centavos. Debe ser mayor que 0.
monedastringOpcionalCódigo ISO 4217. Por defecto USD.
notasstringOpcionalTexto libre de hasta 200 caracteres.
