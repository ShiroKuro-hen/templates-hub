Crea un organigrama de tres niveles para {{empresa}} con una dirección general, direcciones de área y equipos, en forma de árbol anidado con listas (ul y li).
Cada persona se muestra en una tarjeta con avatar de iniciales, nombre y cargo; las conexiones entre niveles son líneas de 1px dibujadas solo con CSS (::before y ::after), sin SVG.
Cada rama con subordinados tiene un botón con aria-expanded y aria-controls que muestra u oculta su lista; el chevron se dibuja con CSS y el foco es visible.
Estilo sobrio y profesional: bordes finos de 1px, radio 8px, sombras suaves, acento azul, tokens CSS con tema claro y oscuro, contraste AA, sin librerías.
