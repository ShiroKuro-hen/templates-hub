Autenticación

Cada petición a la API necesita una clave. Crea una, envíala en la cabecera y rótala sin cortar el servicio.

Crear una clave

Abre Ajustes, entra en Claves de API y pulsa Nueva clave. Copia el valor: solo se muestra una vez.

Enviar la clave

Incluye la clave en la cabecera Authorization de cada petición.

curl https://api.ejemplo.com/v1/pedidos \
  -H "Authorization: Bearer $CLAVE"

Rotar claves

Crea la clave nueva, actualiza tus servicios y revoca la anterior. Rota las claves cada 90 días.
