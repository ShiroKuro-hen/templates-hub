Crea un select personalizado para elegir {{campo}} entre {{opciones}}, siguiendo el patrón ARIA "select-only combobox".
El disparador tiene role="combobox", aria-expanded, aria-controls y aria-activedescendant; la lista usa role="listbox" y role="option" con aria-selected.
Teclado: flechas, Inicio/Fin, Enter o Espacio para elegir, Esc para cerrar, Tab confirma y una letra salta a la opción que empieza por ella. La opción activa lleva una barra fina con el degradado de acento.
Estilo sobrio y profesional: bordes finos de 1px, radio 8px, sombras suaves, acento azul, tokens CSS con tema claro y oscuro.
