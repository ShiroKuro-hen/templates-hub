Crea un selector de selección múltiple para elegir {{elementos}} (por ejemplo, áreas de un proyecto) con campo de búsqueda y chips para lo elegido.
Requisitos: patrón combobox accesible (role="combobox", listbox con aria-multiselectable, aria-activedescendant), flechas para moverse, Enter para marcar o desmarcar,
Esc para cerrar, Retroceso en un campo vacío quita el último chip, filtro sin distinguir tildes, estado vacío con {{mensaje_vacio}} y contador aria-live. Sin librerías externas.
Estilo sobrio y profesional: bordes finos de 1px, radio 8px, sombras suaves, acento azul, tokens CSS con tema claro y oscuro.
