Crea un sistema de toasts para {{aplicacion}} con seis posiciones configurables (arriba y abajo, a izquierda, centro y derecha) elegidas con un grupo de radios.
Cada toast tiene tipo (éxito, info, aviso, error), título, mensaje, botón para cerrar y una barra de tiempo de {{segundos}} segundos; el contenedor usa aria-live="polite".
La posición se controla con un atributo data-pos y CSS, y los toasts se cierran solos. Sin librerías.
Estilo sobrio y profesional: bordes finos de 1px, radio 8px, sombras suaves, acento azul, tokens CSS con tema claro y oscuro.
