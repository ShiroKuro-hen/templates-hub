Crea una conversación con {{contacto}} que muestre un indicador de escritura (tres puntos con degradado y animación suave) y el estado de entrega de cada mensaje propio: Enviado, Entregado y Leído.
Cada estado combina un icono SVG de verificación con una etiqueta de texto (nunca solo color); "Leído" usa el color de acento. Al enviar, el estado avanza solo, aparece "escribiendo" y llega una respuesta.
El indicador tiene un texto oculto con role="status" y respeta prefers-reduced-motion. Sin librerías externas.
Estilo sobrio y profesional: bordes finos de 1px, radio 8px, sombras suaves, acento azul, tokens CSS con tema claro y oscuro.
